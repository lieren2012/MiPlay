# 干净室边界

## 可接受输入

- 公开协议规范、专利公开资料和厂商公开文档。
- 明确允许使用的 Apache-2.0、MIT、BSD 或兼容许可证代码。
- 对用户自有车辆、手机和已知可用转换器进行的行为观察。
- USB、蓝牙、Wi-Fi 的非侵入式抓包和错误日志。

## 禁止输入

- 没有明确许可证的 CatPlay 源码复制、翻译、生成式改写或提交。
- 厂商固件的解密、再分发、私钥、证书或受保护内容提取。
- 绕过 MFi、FairPlay、Apple 鉴权或手机安全机制。
- 把第三方 SDK 二进制重新包装成自有实现。

## 实现记录

每新增协议模块必须记录：

- 规范或行为来源。
- 观察日期和测试设备。
- 对应测试向量。
- 许可证和 NOTICE 要求。
- 无法验证的假设。

## 当前项目关系

当前仓库只包含独立编写的状态机、媒体检查和项目内部仿真线格式。CatPlay 仅作为公开架构和可行性信号被讨论，没有纳入源码或构建产物。
