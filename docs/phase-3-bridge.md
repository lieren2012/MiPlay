# 阶段 3：完整桥接

## 功能范围

- 导航、音乐、系统提示、电话、TTS 和麦克风音频。
- 车机触控、返回、旋钮、媒体键和方向盘按键。
- 手机锁屏、后台限制、蓝牙抢占和来电恢复。
- 自动启动、断线重连、看门狗和日志轮转。
- 媒体状态、电话状态、GPS 和昼夜模式同步。

## 视频策略

优先直接重封装来源侧 H.264：

1. 解析并验证 SPS/PPS、分辨率、帧率和色彩信息。
2. 保持 H.264 载荷，不清码和重编码。
3. 重写容器时间戳并维护单调递增的 CarPlay 时间轴。
4. 参数不兼容时请求关键帧或协商新分辨率。
5. 只有确认无法重封装时，才启用硬编转码，并单独增加性能门槛。

## 音频策略

- 电话和麦克风拥有最高优先级。
- 导航提示不得被音乐混音覆盖。
- 不同采样率通过最小重采样处理；不进行无必要的 AAC 转码。
- 麦克风链路和电话链路中断时，应立即退出通话音频状态。
- 队列溢出时丢弃最旧的媒体音频，永不丢弃当前电话包。

## 输入策略

统一 `InputEvent` 后映射到来源侧（ICCOA Carlink）：

- 触控坐标必须按实际显示区域缩放和裁剪。
- 方控只映射媒体、电话和语音键，不接管车辆安全按键。
- 旋钮方向、按下、返回和长按保留原始语义。
- 输入时间戳必须跨重连保持单调或在会话重置时显式归零。

## 通过条件

- 导航、音乐、通话、麦克风、触控和方控全部可用。
- 连续 4 小时无进程崩溃、无持续内存增长、无车辆系统异常。
- 电话结束后媒体和导航音频能够正确恢复。
- 原车倒车影像和仪表的响应不因桥接器故障而改变。
